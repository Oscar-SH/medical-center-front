# Getting Started with Create React App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

### `Global template to init any frontend project.`

If you need run this project in other port try:
- yarn install / npm install, this command install dependencies from **package.json**
- yarn start -p 4000 / npm run start -- -p 4000, in this command change the port, if you don't need change port, try: yarn start/npm run start
